Embed code test

A test page for the dev copy: each card holds one kind of Phave form embed code, pasted the way the form's Embed code panel gives it. Not linked from the site.

1. The site tag naming the form

The two lines the panel gives when it has the Site's tag line: a copy of the tag with data-phv-embed, over the empty element of that id.

2. The forms.load snippet

The two lines the panel gives when the tag is installed some other way: the empty element, then a script that asks the tag for the form.

3. A line pasted before codes named the tag

The old one-line code, with only the tag in the head to find it.

4. Added after the page loaded

The button adds an element and asks for the form, the way a single-page app would on a route change.
